# 🍔 Responsive Food Delivery Landing Page (OmniFood Demo)

A modern, fully responsive landing page for a food delivery service, built with **HTML, CSS, and JavaScript**.  
This project demonstrates clean UI/UX design, modular code structure, and mobile-first responsiveness.

---

## ✨ Features

### 1. Header + Hero Section
- Logo and navigation bar
- Hero headline: *“Goodbye Junk Food, Hello Super Healthy Food”*
- Two CTA buttons: *“I’m Hungry”* and *“Show me more”*
- Background image with overlay

### 2. How It Works
- Phone mockup image
- Three-step process:
  1. Choose plan and sign up
  2. Pay & download the app
  3. Start ordering!
- App Store & Google Play buttons

### 3. Our Cities
- Grid layout with 4 city cards: Lisbon, London, Berlin, San Francisco
- Each card includes image, name, and quick stats

### 4. Testimonials
- Title: *“Our Customers Can’t Live Without Us”*
- Three testimonial quotes with avatars and names
- Background image with dark overlay

### 5. Pricing Plans
- Three pricing cards: Premium, Pro, Starter
- Feature lists with check/cross icons
- Sign-up buttons

### 6. Footer
- Links: About Us, Blog, Press, iOS App, Android App
- Social media icons
- Copyright line

---

## 📱 Responsiveness
- **Desktop (≥1200px):** Full grid layout  
- **Tablet (≤834px):** Sections stack neatly, grids become 2 columns  
- **Mobile (≤390px):** Single-column layout, collapsible navigation menu  
- Ensures no horizontal scrolling, proper image scaling, and readable text/buttons
